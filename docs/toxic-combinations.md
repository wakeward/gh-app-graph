# Toxic permission combinations

Generated by `cmd/build`.

## Arbitrary Code Execution (Critical)

- **ID:** `arbitrary-code-execution`
- **Permissions:** `workflows:write` + `contents:write`
- **Risk:** Arbitrary Code Execution (Critical)

**Exploit path:** The attacker pushes a malicious workflow file that executes arbitrary shell commands on the GitHub-hosted runner. Requires workflows:write (contents:write alone cannot modify .github/workflows/). Because the workflow runs in the context of the repository, the attacker can exfiltrate environment variables or access cloud provider credentials.
